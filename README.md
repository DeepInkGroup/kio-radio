# Kio Radio

A minimal, dark internet radio player for independent, human-curated stations.

## Features

- Six verified HTTPS radio streams
- Responsive player with clear loading and error states
- Previous/next station and volume controls
- Local favorites, remembered station, and remembered volume
- Spacebar playback and arrow-key station navigation
- Reduced-motion and keyboard-focus support
- Zero runtime dependencies

## Run locally

```bash
npm start
```

Then open [http://127.0.0.1:4173](http://127.0.0.1:4173).

Browsers require a click before audio playback. Stream availability can vary by location and broadcaster uptime.

## Stations

Kio Radio currently tunes into [KEXP](https://www.kexp.org/streaming-urls/), [WFMU](https://www.wfmu.org/audiostream.shtml), and four [Radio Paradise](https://radioparadise.com/) mixes. All audio remains hosted and operated by the respective broadcasters.
